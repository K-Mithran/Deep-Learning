\section*{1. Objective}

The objective of this experiment is twofold. First, to understand the working principle of an Artificial Neuron and implement a Single Layer Perceptron from scratch for binary classification, using the Banknote Authentication dataset to train and evaluate the model, studying the effect of feature normalization, analysing the learning behaviour using different plots, and evaluating the classifier using standard performance metrics such as Accuracy, Precision, Recall and F1-score. Second, to implement the Perceptron Learning Algorithm from scratch in Python and use it to learn the OR, AND and NOT logic gates, recording the weights and bias after every individual weight update, visualizing the decision boundary at every stage of learning, and verifying that a Single Layer Perceptron can successfully converge on these gates because they represent linearly separable functions.
\section*{2. Background Theory}

Artificial Neural Networks are computational models inspired by the functioning of biological neurons. The fundamental processing unit of an Artificial Neural Network is the Artificial Neuron. Each neuron receives several input features, multiplies them with trainable weights, adds a bias value and passes the result through an activation function to generate an output.

The Single Layer Perceptron proposed by Frank Rosenblatt is one of the earliest supervised learning algorithms. It is capable of solving only linearly separable binary classification problems. During training, the perceptron iteratively updates its weights and bias using the perceptron learning rule until the classification error is minimized.


%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%



The Perceptron, introduced by Frank Rosenblatt, is one of the earliest supervised learning algorithms capable of solving binary classification problems that are linearly separable. Logic gates such as OR, AND and NOT are classical examples of linearly separable Boolean functions, since a single straight line (in two input dimensions) or a single threshold point (in one input dimension) is sufficient to correctly separate the output classes 0 and 1.

During training, the perceptron computes a weighted sum of its inputs, passes this sum through a Step Activation Function, and compares the resulting prediction with the true target value. Whenever the prediction is incorrect, the weights and bias are updated immediately (online learning), and training continues until an entire pass over all input combinations produces zero misclassifications, at which point the perceptron is said to have converged.
\newpage

\subsection*{Mathematical Formulation}

The weighted sum of the inputs is

\[
z=\mathbf{w}^{T}\mathbf{x}+b
\]

where

\begin{itemize}
\item $\mathbf{x}$ denotes the input feature vector.
\item $\mathbf{w}$ denotes the weight vector.
\item $b$ denotes the bias.
\item $z$ denotes the weighted sum.
\end{itemize}

The output of the perceptron is

\[
\hat{y}=f(z)
\]

where $f(z)$ represents the activation function.

The perceptron learning rule updates the weights according to

\[
\mathbf{w}_{new}
=
\mathbf{w}_{old}
+
\eta
(y-\hat{y})
\mathbf{x}
\]

The bias is updated using

\[
b_{new}
=
b_{old}
+
\eta
(y-\hat{y})
\]

where

\begin{itemize}
\item $\eta$ is the learning rate.
\item $y$ is the actual class.
\item $\hat{y}$ is the predicted class.
\end{itemize}


%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%



The weighted sum of the inputs is

\[
z=\mathbf{w}^{T}\mathbf{x}+b
\]

where $\mathbf{x}$ is the input feature vector, $\mathbf{w}$ is the weight vector and $b$ is the bias. The predicted output is

\[
\hat{y}=f(z)
\]

where $f(z)$ is the Step Activation Function. Whenever $\hat{y}\neq y$, the weights and bias are updated according to the Perceptron Learning Rule

\[
\mathbf{w}_{new}=\mathbf{w}_{old}+\eta(y-\hat{y})\mathbf{x}
\]

\[
b_{new}=b_{old}+\eta(y-\hat{y})
\]

where $\eta$ is the learning rate, $y$ is the true class and $\hat{y}$ is the predicted class. In this experiment, $\eta = 0.1$ and the weights and bias were both initialized to zero.
\section*{3. Activation Function}

An activation function determines the output of a neuron based on its weighted input. In this experiment, the Step Activation Function is employed because the problem involves binary classification. The function produces either 0 or 1 depending on the value of the weighted sum.

\[
f(z)=
\begin{cases}
1,&z\ge0\\
0,&z<0
\end{cases}
\]

The Step Activation Function is simple and computationally efficient. However, it is not differentiable and therefore cannot be used with gradient-based optimization algorithms such as backpropagation.

\section*{10. Discussion}

The implementation of the Single Layer Perceptron demonstrated that a simple linear classifier can effectively solve linearly separable binary classification problems, a conclusion reinforced across both the Banknote Authentication task and the OR, AND and NOT logic gates studied in this report. The Banknote Authentication dataset proved highly suitable for perceptron learning because the two classes become nearly separable after feature normalization, while the OR, AND and NOT gates confirmed the same principle in a simpler, fully controlled setting, since each is a classical example of a linearly separable Boolean function.

The training error decreased considerably over successive epochs on the banknote task, indicating that the perceptron successfully learned an appropriate decision boundary, and the gradual stabilization of both the weights and bias further confirmed convergence of the learning algorithm. The evaluation metrics indicate excellent classification performance, with the model achieving an Accuracy of 98.18\%, Precision of 100.00\%, Recall of 96.03\% and an F1-Score of 97.98\%, demonstrating that the implemented classifier generalized well on unseen testing samples. The learning rate experiment further showed that smaller learning rates (0.001 and 0.01) produced slightly better performance than a larger learning rate (0.1), since larger learning rates resulted in comparatively larger weight updates, producing a slight reduction in testing accuracy.
\newpage

The logic gate experiments illustrate the same convergence behaviour at the level of individual weight updates. The OR gate converged fastest among the two-input gates, requiring only 5 updates, since its positive class occupies three of the four input corners, making it comparatively easy for a single line to isolate the sole negative example $(0,0)$. The AND gate required more updates (8 in total) because its positive class is a single corner point $(1,1)$, requiring the boundary to be pushed further away from the origin before all three negative points could be placed correctly on the negative side. The NOT gate, having only two possible input values, converged almost immediately in just 2 updates. In every case, the weights and bias changed monotonically towards a stable configuration and then stopped changing entirely once an epoch produced zero misclassifications, which is the defining signature of convergence, and these results align exactly with perceptron convergence theory, which guarantees that the algorithm will find a separating hyperplane in a finite number of steps whenever the underlying data is linearly separable.

Although the Single Layer Perceptron performs well on linearly separable datasets and logic gates alike, it cannot solve non-linearly separable problems such as XOR. Such problems require multilayer neural networks together with differentiable activation functions and backpropagation learning.
\section*{11. Conclusion}

In this experiment, a Single Layer Perceptron was successfully implemented from scratch using Python in Google Colab and evaluated on two complementary tasks: binary classification on the Banknote Authentication dataset, and learning of the OR, AND and NOT logic gates. For the banknote classification task, the dataset was explored, preprocessed and normalized before training the classifier, and the perceptron learning algorithm successfully updated the weights and bias over multiple epochs, resulting in a well-trained binary classifier; the generated plots clearly illustrated the learning behaviour of the model through training error reduction, weight convergence, bias evaluation and learning-rate comparison, and the trained model achieved high classification performance with an Accuracy of 98.18\%, demonstrating that the Single Layer Perceptron is an effective solution for linearly separable binary classification tasks.

For the logic gate task, the Perceptron Learning Algorithm was used to successfully learn the OR, AND and NOT gates, with the weights and bias logged after every individual update and the decision boundary visualized at every stage of learning, clearly illustrating how the perceptron incrementally rotates and shifts its boundary until all training examples are classified correctly; all three gates converged within a handful of epochs (3 to 4), confirming that the Single Layer Perceptron is a reliable and efficient solution for linearly separable binary classification problems of this kind.

Taken together, the experiment provided practical understanding of activation functions, perceptron learning, parameter updates and performance evaluation metrics, and demonstrated consistently, across both a real-world dataset and fundamental logic gates, that the Single Layer Perceptron is an effective and reliable solution wherever the underlying classification problem is linearly separable.
